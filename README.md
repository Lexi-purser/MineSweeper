 # MineSweeper
AI Agent created to solve minesweeper


## 🚀 How to Run

1. **Clone or download** the repository.

2. **Navigate** to the `mine-sweeper-agent` directory:
   ```bash
   cd mine-sweeper-environment/mine-sweeper-agent/
   ```

## 🕹️ Command Usage
```bash
python3 agent2.py {0,1,2} {y,n} {y,n}
```
Where:
- {0,1,2}	Board size:
   - 0 → 9×9 (10 mines)
   - 1 → 16×16 (40 mines)
   - 2 → 21×21 (99 mines)
- {y,n}	Start game with first choice on a zero-tile?
   - y = Yes, n = No
- {y,n}	Render game with graphics?
   - y = Yes, n = No
### If you need a reminder use the --help flag
-h, --help	Show help message and usage examples
### Example
```bash
python3 agent2.py 1 y y
```

- Uses a 16×16 board with 40 mines
- Ensures the first click is on a zero-tile
- Renders the game graphics in the terminal
