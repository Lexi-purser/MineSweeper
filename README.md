# MineSweeper
AI Agent created to solve minesweeper


## 🚀 How to Run

1. **Clone or download** the repository.

2. **Navigate** to the `mine-sweeper-agent` directory:
   ```bash
   cd mine-sweeper-environment/mine-sweeper-agent/
   ```

    Run an agent file. For example, to run agent2.py:
   ```bash
    python3 agent2.py --help
   ```

🕹️ Command Usage

python3 agent2.py {0,1,2} {y,n} {y,n}

📌 Positional Arguments
Argument	Description
- {0,1,2}	Board size:
   - 0 → 9×9 (10 mines)
   - 1 → 16×16 (40 mines)
   - 2 → 21×21 (99 mines)
- {y,n}	Start game with first choice on a zero-tile?
   - y = Yes, n = No
- {y,n}	Render game with graphics?
   - y = Yes, n = No
🛠️ Optional Flags
Flag	Description
-h, --help	Show help message and usage examples
📌 Example

python3 agent2.py 1 y y

    Uses a 16×16 board with 40 mines

    Ensures the first click is on a zero-tile

    Renders the game graphics in a window

🧠 AI Agent Notes

    Each agent may use a different solving algorithm such as rule-based logic, constraint satisfaction, or probabilistic inference.

    Feel free to explore each agent file to compare their performance and techniques!
